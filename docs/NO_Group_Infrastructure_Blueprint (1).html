N.O Group Master Infrastructure Blueprints

Strategic Architecture Manifest
This document archives the core open-source repositories secured as the foundational layers of the N.O Group sovereign tech stack.

1. User-Facing Corporate Applications

N.O Workspace (Nextcloud Core)

  • Repository Link: https://github.com/nextcloud/all-in-one
  • Strategic Reason: Instantly deploys a complete, secure alternative to Google Workspace and Microsoft 365. Contains modules for files, team calendars, relational databases, and server-side automation. The All-in-One architecture allows rapid deployment of the corporate suite under the N.O brand.

N.O Connect (Signal Ecosystem)

  • Repository Links:
    • Backend Server: https://github.com/signalapp/Signal-Server
    • Android Client: https://github.com/signalapp/Signal-Android
    • iOS Client: https://github.com/signalapp/Signal-iOS
    • Desktop Client: https://github.com/signalapp/Signal-Desktop
  • Strategic Reason: Provides an unhackable, military-grade internal messaging framework. Inherits the cryptographic Signal Protocol for absolute end-to-end encryption. Modifying the frontend clients allows full layout customization to N.O Group aesthetics, while keeping the untouched backend server secure and easy to sync with official updates.

N.O Office (LibreOffice Core)

  • Repository Link: https://github.com/LibreOffice/core
  • Strategic Reason: Serves as the foundational codebase for a heavy-duty local desktop office suite alternative to Microsoft Word, Excel, and PowerPoint. Ensures N.O Group computers have robust, sovereign processing power over offline business documents without third-party tracking.

2. Tungsten & Vortex Engine Infrastructure

Tungsten Execution Core (Docker/Moby Core)

  • Repository Link: https://github.com/moby/moby
  • Strategic Reason: The runtime foundation for Tungsten's drag-and-drop builder canvas. Allows Tungsten to instantly spin up, build, and preview sandboxed applications inside isolated environments without threatening the host system.

Tungsten AI Brain (Ollama)

  • Repository Link: https://github.com/ollama/ollama
  • Strategic Reason: Orchestrates local generative AI compilation. Embedded into Tungsten to drive text-to-UI component rendering, code generation, and automated canvas debugging without paying recurring API fees to third parties.

Tungsten Canvas Logic (Litegraph.js)

  • Repository Link: https://github.com/jagenjo/litegraph.js
  • Strategic Reason: Powers the physical visual engine for Tungsten's visual programming node graphs, enabling complex drag-and-drop structural wiring between interface components and backend models.

Vortex Database Engine (PostgreSQL)

  • Repository Link: https://github.com/postgres/postgres
  • Strategic Reason: The foundational relational database architecture for Vortex (Backend-as-a-Service). Handles relational data storage, querying, and structural tables smoothly at absolute enterprise scales. It is also the underlying engine required by Workspace and Connect.

Vortex Traffic Routing (Caddy Server)

  • Repository Link: https://github.com/caddyserver/caddy
  • Strategic Reason: Acts as the reverse proxy traffic cop for Vortex. Automates security encryption certificates (SSL/HTTPS) on the fly, allowing apps generated by Tungsten to immediately launch safely to live custom domains.

3. Proprietary N.O Group Pillars (Private Repositories)

  • Tungsten (Active Development): Visual drag-and-drop AI layout editor, code writer, and interactive software creator canvas.
  • Vortex (Active Development): In-house Backend-as-a-Service (BaaS) handling authentication routing, database execution, container pipelines, and custom runtime parameters, paired natively with its own integrated SDK.
